# 自动审查证据

本目录保存有范围的代码审查输入和结果。审查输入用于说明意图、范围及约束，不是当前功能说明，也不证明实现或验收已经通过；当前事实仍以专题页、代码和可复现结果为准。

四份冻结的 unified diff 保留原始上下文前缀；空行前的单个空格和 Go 缩进前的上下文空格属于补丁格式。[局部属性](.gitattributes)仅对这四个文件关闭对应两类空白误报，不改变原始证据，也不放宽应用源码的格式检查。
