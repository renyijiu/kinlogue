## 仍未证明的边界

- 降级恢复入口有自动化覆盖，尚无独立真实窗口验收。
- File Provider 可能延迟同步系统调用，进而延迟取消与退出；实际 Provider、其他 macOS/Intel、完整键盘及 VoiceOver 矩阵未执行。
- 发布以 rename 为提交点；之后父目录同步失败不回滚已发布文件，不能承诺断电持久性。
- 极窄的“准备成功、令牌发布前取消、同时精确清理失败”组合可能使后续准备需要退出重启；旧库不会被替换。该组合的故障注入尚未执行。
- 多 GiB 备份时延与取消体验、使用旧 App 安装包的完整升级流程尚未验证。
